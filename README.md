## Octofit Tracker backend

The logic tier for the Octofit Tracker app is in `octofit-tracker/backend` and runs on port `8000`.

- Local development: `http://localhost:8000`
- GitHub Codespaces: `https://$CODESPACE_NAME-8000.app.github.dev`

The API exposes the main collection routes under `/api/` for users, teams, activities, leaderboard, and workouts.
